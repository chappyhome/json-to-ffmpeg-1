JSON-to-FFmpeg 输入 JSON 语法规则文档：
JSON-to-FFmpeg 输入格式语法规则
一、顶层结构（必填）
{
  "version": 1,           // 必须为 1
  "inputs": {...},        // 资源池（对象）
  "tracks": {...},        // 轨道集合（对象）
  "output": {...},        // 输出配置（对象）
  "transitions": [...]    // 转场效果（数组，可为空）
}
✅ 校验规则
必须包含 version, inputs, tracks, output 四个字段
version 必须等于 1
transitions 可选，但如果存在必须是数组
二、inputs（资源池）
2.1 基本结构
"inputs": {
  "资源名称1": { /* Source 对象 */ },
  "资源名称2": { /* Source 对象 */ }
}
2.2 Source 对象（通用字段）
{
  "type": "video" | "audio" | "image" | "text",  // 必填
  "file": "路径或URL",                            // 必填（text类型可为空字符串）
  "hasAudio": boolean,                           // 必填
  "hasVideo": boolean,                           // 必填
  "duration": number,                            // 必填（秒）
  "metadata": {...}                              // 可选，根据类型不同
}
2.3 metadata 按类型分类
📹 Video 类型
无特殊 metadata
🎵 Audio 类型
"metadata": {
  "audioType": "bgm" | "sfx" | "narration",  // 可选，默认 "sfx"
  
  // BGM 专用（背景音乐）
  "loop": boolean,           // 循环播放
  "fadeIn": number,          // 淡入时长（秒）
  "fadeOut": number,         // 淡出时长（秒）
  
  // SFX 专用（音效）
  "fadeIn": number,          // 淡入时长（秒）
  "fadeOut": number,         // 淡出时长（秒）
  
  // Narration 专用（旁白）
  "fadeIn": number,          
  "fadeOut": number,
  "subtitleUrl": "https://...",        // SRT字幕URL（与subtitleFile二选一）
  "subtitleFile": "path/to/file.srt",  // SRT本地路径（优先级高）
  "language": "zh" | "en" | "...",     // 语言代码
  "speaker": "说话者名称",
  "subtitleStyle": {                   // 字幕样式（可选）
    "fontFamily": "Arial",
    "fontSize": 28,
    "fontColor": "#FFFFFF",
    "backgroundColor": "#00000099",
    "position": "top" | "bottom" | "middle",
    "marginV": 30
  }
}
🖼️ Image 类型
"metadata": {
  "imageType": "static" | "animated",  // 必填
  "format": "png" | "jpg" | "gif",     // 可选
  
  // animated 专用
  "loop": boolean,       // 是否循环
  "frameRate": number    // 帧率
}
📝 Text 类型
"metadata": {
  "text": "显示的文本内容",        // 必填
  "fontFamily": "Arial",          // 可选，字体名称
  "fontFile": "/path/to/font.ttf", // 可选，字体文件路径
  "fontSize": 72,                 // 可选，字体大小
  "fontColor": "#FFFFFF",         // 可选，文字颜色
  "backgroundColor": "#00000080", // 可选，背景颜色（支持透明度）
  "textAlign": "left" | "center" | "right",  // 可选，对齐方式
  "fontWeight": "normal" | "bold",           // 可选，字重
  "stroke": {                     // 可选，描边
    "color": "#000000",
    "width": 2
  },
  "shadow": {                     // 可选，阴影
    "color": "#00000080",
    "blur": 4,
    "offsetX": 2,
    "offsetY": 2
  },
  "boxPadding": number            // 可选，内边距
}
✅ 校验规则
每个 input 的键名（资源名称）必须唯一
type 必须是 video/audio/image/text 之一
hasAudio 和 hasVideo 必须与 type 对应：
video: hasVideo=true
audio: hasAudio=true, hasVideo=false
image: hasVideo=true, hasAudio=false
text: hasVideo=true, hasAudio=false
duration 必须 > 0（除非是 text 或 static image 可以为 0）
text 类型的 metadata.text 必须存在且非空
三、tracks（轨道集合）
3.1 基本结构
"tracks": {
  "轨道名称1": { /* Track 对象 */ },
  "轨道名称2": { /* Track 对象 */ }
}
3.2 Track 对象
{
  "type": "video" | "audio",  // 必填
  "clips": [...]              // Clip 数组，必填
}
3.3 Clip 对象（通用字段）
{
  "name": "唯一clip名称",            // 必填，全局唯一
  "source": "inputs中的资源名",      // 必填，必须存在于inputs
  "timelineTrackStart": number,     // 必填，在时间线上的起始秒数
  "duration": number,               // 必填，持续秒数
  "sourceStartOffset": number,      // 必填，源文件起始偏移秒数
  "clipType": "video" | "audio" | "image" | "text",  // 必填
  
  // video/image/text 专用
  "transform": {
    "x": number,        // 必填，X坐标
    "y": number,        // 必填，Y坐标
    "width": number,    // 必填，宽度
    "height": number,   // 必填，高度
    "rotation": number, // 必填，旋转角度（度）
    "opacity": number   // 必填，不透明度 0-1
  },
  
  // audio 专用
  "volume": number      // 必填，音量 0-1
}
✅ 校验规则
每个 track 的键名（轨道名称）必须唯一
Track 的 type 必须是 video 或 audio
每个 Clip 的 name 在整个 JSON 中必须全局唯一
Clip 的 source 必须存在于 inputs 中
Clip 的 clipType 必须与引用的 source 的 type 匹配
Track 类型与 Clip 类型匹配：
type: "video" 的 track 只能包含 clipType: "video/image/text" 的 clip
type: "audio" 的 track 只能包含 clipType: "audio" 的 clip
video/image/text clip 必须有 transform
audio clip 必须有 volume
timelineTrackStart 和 duration 必须 ≥ 0
opacity 必须在 0-1 之间
volume 必须在 0-1 之间
四、transitions（转场效果）
4.1 基本结构
"transitions": [
  {
    "type": "fade" | "smoothup" | "smoothdown" | "circlecrop" | "squeezev" | "squeezeh" | "...",
    "duration": number,        // 转场持续时长（秒）
    "from": "clip名称" | null,  // 起始clip（null表示从黑屏开始）
    "to": "clip名称" | null     // 结束clip（null表示到黑屏结束）
  }
]
4.2 支持的转场类型
fade - 淡入淡出
smoothup - 平滑向上
smoothdown - 平滑向下
circlecrop - 圆形裁剪
squeezev - 垂直挤压
squeezeh - 水平挤压
等（参考 FFmpeg xfade 滤镜支持的类型）
✅ 校验规则
type 必填
duration 必须 > 0
from 和 to 可以为 null，但不能同时为 null
如果 from 或 to 不为 null，必须是 tracks 中存在的 clip name
转场只适用于 video clips
五、output（输出配置）
5.1 完整结构
{
  "tempDir": "./tmp",              // 可选，临时目录
  "file": "output.mp4",            // 必填，输出文件名
  "videoCodec": "libx264",         // 可选，视频编码器
  "audioCodec": "aac",             // 可选，音频编码器
  "width": 1920,                   // 必填，输出宽度
  "height": 1080,                  // 必填，输出高度
  "audioBitrate": "320k",          // 可选，音频比特率
  "preset": "veryfast",            // 可选，编码预设
  "crf": 23,                       // 可选，视频质量
  "framerate": 30,                 // 必填，帧率
  "flags": ["-pix_fmt", "yuv420p"], // 可选，额外的FFmpeg标志
  "startPosition": 0,              // 必填，渲染起始秒数
  "endPosition": 10,               // 必填，渲染结束秒数
  "scaleRatio": 1.0                // 可选，缩放比例
}
✅ 校验规则
file, width, height, framerate, startPosition, endPosition 必填
width 和 height 必须 > 0
framerate 必须 > 0
endPosition 必须 > startPosition
scaleRatio 如果存在必须 > 0
crf 通常在 0-51 之间（越小质量越高）
六、常见错误检查清单
❌ 错误 1：资源引用不存在
// ❌ 错误
"clips": [{"source": "video1", ...}]  // 但 inputs 中没有 "video1"
❌ 错误 2：clip name 重复
// ❌ 错误
"clips": [
  {"name": "clip1", ...},
  {"name": "clip1", ...}  // 重复！
]
❌ 错误 3：类型不匹配
// ❌ 错误
"video_track": {
  "type": "video",
  "clips": [{"clipType": "audio", ...}]  // 类型不匹配！
}
❌ 错误 4：audio clip 使用了 transform
// ❌ 错误
{"clipType": "audio", "transform": {...}}  // audio不需要transform！
❌ 错误 5：video clip 缺少 transform
// ❌ 错误
{"clipType": "video", "volume": 1.0}  // 缺少transform！
❌ 错误 6：text 类型缺少 metadata.text
// ❌ 错误
"text1": {
  "type": "text",
  "metadata": {"fontSize": 72}  // 缺少 text 字段！
}
❌ 错误 7：hasAudio/hasVideo 与 type 不符
// ❌ 错误
"audio1": {
  "type": "audio",
  "hasAudio": false,  // 应该是 true！
  "hasVideo": true    // 应该是 false！
}
七、快速验证步骤
当你收到一个 JSON 时，按以下顺序检查：
结构检查
 包含 version, inputs, tracks, output？
 version === 1？
 transitions 是数组（或不存在）？
inputs 检查
 每个 input 有 type, file, hasAudio, hasVideo, duration？
 hasAudio/hasVideo 与 type 匹配？
 text 类型有 metadata.text？
 audio 的 audioType 是 bgm/sfx/narration 之一（或不存在）？
tracks 检查
 每个 track 有 type 和 clips？
 每个 clip 有 name, source, timelineTrackStart, duration, sourceStartOffset, clipType？
 clip 的 source 存在于 inputs 中？
 clip 的 name 全局唯一？
 video/image/text clip 有 transform？
 audio clip 有 volume？
 track.type 与 clip.clipType 匹配？
transitions 检查
 每个 transition 有 type, duration, from, to？
 from 和 to 引用的 clip 存在？
output 检查
 有 file, width, height, framerate, startPosition, endPosition？
 endPosition > startPosition？
 数值合理（width/height > 0, framerate > 0）？
八、最小可用示例
{
  "version": 1,
  "inputs": {
    "video1": {
      "type": "video",
      "file": "input.mp4",
      "hasAudio": false,
      "hasVideo": true,
      "duration": 10
    }
  },
  "tracks": {
    "main_track": {
      "type": "video",
      "clips": [{
        "name": "clip1",
        "source": "video1",
        "timelineTrackStart": 0,
        "duration": 5,
        "sourceStartOffset": 0,
        "clipType": "video",
        "transform": {
          "x": 0, "y": 0,
          "width": 1920, "height": 1080,
          "rotation": 0, "opacity": 1
        }
      }]
    }
  },
  "transitions": [],
  "output": {
    "file": "output.mp4",
    "width": 1920,
    "height": 1080,
    "framerate": 30,
    "startPosition": 0,
    "endPosition": 5
  }
}
